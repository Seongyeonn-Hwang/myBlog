기존에 Obsidian vault를 통째로 커밋하던 방식에서 벗어나, 이제는 `blog/` 폴더에 마크다운 파일을 직접 넣는 방식으로 블로그를 다시 시작한다.

기존 vault는 `obsidian-vault/` 폴더로 옮겼고 git 추적에서 제외했다. 더 이상 Obsidian 설정 파일이나 개인적인 메모가 이 저장소에 섞이지 않는다.

## 글 쓰는 법

1. `blog/` 폴더 안에 `.md` 파일을 만든다. 파일명이 곧 글 제목이다.
2. `update.bat`을 실행하거나 그냥 git push 하면 GitHub Actions가 자동으로 목록을 갱신한다.
3. 이미지는 표준 마크다운 문법(`![대체텍스트](경로)`)을 쓴다.

앞으로 여기에 글을 채워나갈 예정이다.
