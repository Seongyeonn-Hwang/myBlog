  blog.js 기능 정리

  1. 프론트매터 제거 (stripFrontmatter)

  - 마크다운 파일 상단의 --- 블록(메타데이터)을 제거하고 본문만 남김

  2. 보안 콘텐츠 숨김 (hideSensitiveContent)

  - (!보안)내용(보안!) 형식으로 감싼 텍스트를 ■로 마스킹
  - 공백과 줄바꿈은 그대로 유지해 레이아웃 보존

  3. 마크다운 → HTML 변환 (mdToHtml)

  라이브러리 없이 자체 구현:
  - 표: | col | 형식 → <table> 변환 (먼저 추출 후 복원하는 플레이스홀더 방식)
  - 헤딩: #~`######→~`
  - 볼드/이탤릭: **text** / *text*
  - 리스트: -, *, 숫자 목록, 탭 들여쓰기 목록 → <li>
  - 가로선: --- → <hr/>
  - 단락: 빈 줄 → </p><p>, 줄바꿈 → <br/>
  - XSS 방지를 위해 &, <, > 이스케이프 처리

  4. 포스트 그리드 렌더링 (renderPosts)

  - 전체 또는 날짜 필터 기준으로 POSTS 배열을 필터링
  - 각 포스트를 카드(제목, 날짜, 미리보기 80자)로 렌더링
  - 포스트 수 표시 (N posts)

  5. 모달 팝업 (openPost / closeModal)

  - 카드 클릭 시 모달 열어 전체 내용을 HTML로 렌더링
  - 닫기 방법 3가지: 닫기 버튼, 배경 클릭, Escape 키

  6. 날짜 필터

  - .filter-btn 버튼 클릭 시 해당 연도/월 기준으로 포스트 필터링
  - 활성 버튼 스타일 토글
