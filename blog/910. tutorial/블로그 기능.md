  index.html (메인 페이지)
  1. 실시간 시계 — 현재 KST 시간 표시
  2. 주가 지수 — KOSPI / KOSDAQ / NASDAQ 실시간 시세 (Yahoo Finance API 사용)
  3. 방문자 추적 — GoatCounter 스크립트 (모든 페이지 공통)

  blog.html (블로그)
  4. 파일 트리 — ASCII 트리 형식으로 폴더/파일 목록 표시
  5. 폴더 접기/펼치기 — [+]/[-] 클릭으로 토글
  6. New 배지 — 7일 이내 작성된 파일에 ✦ New 표시
  7. 날짜 표시 — 각 파일 옆에 작성 날짜
  8. 마크다운 렌더링 — 파일 클릭 시 마크다운 파싱해서 표시
  9. Obsidian 문법 지원 — [[wiki-link]], ==하이라이트==, Callout 블록
  10. 보안 콘텐츠 마스킹 — (!보안)...(보안!) 범위를 ■로 가림
  11. 상태 태그 — (delay), (working), (pending), (important) 배지 렌더링
  12. Habit Tracker 특별 렌더링 — 연간 그리드 + 스트릭 카운트
  13. 브라우저 히스토리 — 뒤로가기 지원 (history.pushState)

  about.html
  14. 사진 갤러리 — about_content.js에서 이미지 목록 로드해서 그리드 표시

  visitor_report.html
  15. 방문자 통계 대시보드 — GoatCounter API로 누적/오늘 방문수, 인기 페이지, 유입 경로 표시
