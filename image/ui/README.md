# UI 자산 디자인 가이드라인

블로그의 패널·버튼·구분선 테두리에 쓰이는 이미지들입니다.

현재 들어있는 파일은 **자리표시자**입니다. 규격만 맞으면 되므로,
**같은 파일 이름으로 덮어쓰기만** 하면 코드 수정 없이 바로 적용됩니다.

확인: `./build.sh && npx serve _site` → http://localhost:3000/ui-preview

---

## 1. 9-slice란 (테두리 이미지 5개가 이 방식입니다)

작은 타일 한 장을 3×3으로 잘라서, **모서리 4개는 고정, 변 4개는 늘려서 반복,
가운데는 버립니다.** 그래서 패널이 어떤 크기가 되든 테두리가 뭉개지지 않습니다.

```
 ┌────┬───────────┬────┐
 │ 고정│  ← 늘어남 → │ 고정│   ← 위쪽 8px
 ├────┼───────────┼────┤
 │  ↑ │           │  ↑ │
 │늘어남│   투명    │늘어남│
 │  ↓ │  (버려짐)  │  ↓ │
 ├────┼───────────┼────┤
 │ 고정│  ← 늘어남 → │ 고정│   ← 아래쪽 8px
 └────┴───────────┴────┘
   8px              8px
```

CSS는 이렇게 씁니다.

```css
border-image: url("image/ui/panel.png") 8 / 4px repeat;
/*                                      ↑     ↑
              원본에서 잘라낼 안쪽 여백 8px    화면에 그릴 두께 4px */
```

### 핵심 규칙 두 가지

**규칙 1 — 이미지 크기 = `2 × slice + 1`**

`8`을 잘라내려면 이미지는 `8 + 1 + 8 = 17px`이어야 합니다.
가운데 1px은 어차피 버려지지만, 이게 없으면 좌우 슬라이스가 겹칩니다.

**규칙 2 — 2배 해상도로 그리고 1배로 표시**

`slice 8`을 `4px`로 그립니다. 고해상도 화면에서 선명하게 나오기 때문입니다.
즉 **실제 화면에 보이는 테두리는 4px**이고, 그림은 그 2배인 8px로 그립니다.

> 참고: 팩토리오도 정확히 이 규격입니다. 그쪽 `main.css`의 패널은 전부
> `17x17px, slice 8 → 4px`이고, 더 두꺼운 패널만 `21x21px, slice 10 → 5px`입니다.

### 가운데는 비워두세요

`border-image`에 `fill` 키워드를 쓰지 않으므로 **가운데 1px은 버려집니다.**
패널 안쪽 배경은 CSS `background-color`가 칠합니다. 타일에는 **테두리 링만** 그리시면 됩니다.
가운데를 투명하게 두셔도 되고 아무 색이나 칠하셔도 무시됩니다.

## 2. 파일 목록

전부 `image/ui/` 에 넣습니다. **파일 이름을 정확히 맞춰주세요.**

| 파일 이름 | 크기 | slice / 두께 | 용도 | 필수 |
|---|---|---|---|---|
| `panel.png` | **17 × 17** | 8 → 4px | 글 전체를 감싸는 바깥 패널 | ✅ |
| `panel-inset.png` | **17 × 17** | 8 → 4px | 움푹 들어간 박스. 그림·차트·인용을 본문에서 분리 | ✅ |
| `button.png` | **17 × 17** | 8 → 4px | 버튼 기본 상태 | ✅ |
| `button-hover.png` | **17 × 17** | 8 → 4px | 버튼에 마우스 올렸을 때 | ⬜ |
| `button-active.png` | **17 × 17** | 8 → 4px | 버튼 눌렀을 때 (보통 베벨을 반전) | ⬜ |
| `separator.png` | **16 × 12** | (반복 배경) | 섹션 사이 가로 구분선 | ⬜ |

필수 3개만 있어도 동작합니다. 선택 항목이 없으면 아래처럼 대체됩니다.

- `button-hover.png` 없음 → `button.png`을 밝기 필터로 대신
- `button-active.png` 없음 → `button.png` 그대로
- `separator.png` 없음 → 단색 1px 선

### `separator.png`만 규격이 다릅니다

9-slice가 아니라 **가로로 반복(`repeat-x`)되는 띠**입니다.

- 크기: **16 × 12px** (2배 기준. 화면에는 높이 6px로 표시)
- 좌우 끝이 이어지도록 그려주세요 — 옆으로 계속 반복됩니다
- 높이를 바꾸고 싶으시면 알려주세요. CSS에서 맞추겠습니다

## 3. 형식 요구사항

- **PNG, RGBA (32bit, 투명도 포함)** — 투명 영역이 반드시 필요합니다
- 색 프로파일·메타데이터는 없는 게 좋습니다 (용량만 늘어납니다)
- 안티앨리어싱은 **끄고** 픽셀 단위로 그리시는 걸 권합니다. 17px짜리 그림이라
  흐릿하게 그리면 화면에서 뭉개집니다
- 파일 하나에 **2KB를 넘기지 마세요.** 지금 자리표시자는 전부 121바이트입니다
- SVG는 `border-image`에서 슬라이스가 브라우저마다 다르게 동작해서 권하지 않습니다

### 그리실 때

17×17 캔버스에서 **바깥 8px 링**만 칠하시면 됩니다. 실제로 화면에 보이는 건
그 링뿐이고, 모서리 8×8 정사각형 4개가 패널 네 귀퉁이에 그대로 박힙니다.
그러니 **모서리 8×8 안에서 디자인이 완결**되어야 합니다.

솟아 보이게 하려면 위/왼쪽을 밝게 아래/오른쪽을 어둡게,
움푹 들어가 보이게 하려면 그 반대로 칠하면 됩니다.

## 4. 색상 토큰

이미지로 안 되는 부분(배경·글자색)은 CSS 변수로 잡혀 있습니다.
`blog.html` 상단 `:root`에서 바꾸시거나, 원하는 값을 알려주시면 반영하겠습니다.

| 변수 | 현재값 | 용도 |
|---|---|---|
| `--ui-panel-bg` | `#242424` | 바깥 패널 안쪽 배경 |
| `--ui-inset-bg` | `#1b1b1b` | 움푹한 박스 안쪽 배경 |
| `--ui-button-bg` | `#333333` | 버튼 배경 |
| `--ui-button-fg` | `#c9cbd0` | 버튼 글자색 |
| `--ui-caption` | `#8a8d93` | 그림 캡션 글자색 |

## 5. 넘겨주시는 방법

1. 이 폴더(`image/ui/`)의 파일을 **같은 이름으로 덮어쓰기**
2. `./build.sh && npx serve _site` → http://localhost:3000/ui-preview 에서 확인
3. 괜찮으면 `git add -- image/ui && git commit && git push`

규격이 안 맞거나 다른 구성을 원하시면 (예: 패널을 21×21 두꺼운 걸로,
버튼 상태를 더 추가) 말씀해주세요. CSS 쪽을 맞추겠습니다.

이미지 대신 **참고 스크린샷이나 원하는 느낌**만 주셔도 제가 타일을 만들어볼 수 있습니다.
